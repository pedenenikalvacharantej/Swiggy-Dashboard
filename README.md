DATA & FORMULA GUIDE         
• Date can be used with TEXT, MONTH and  WEEKNUM  to create Day, Month, Week and Quarter 
helper fields.            
• Recommended Day formula: =TEXT(B2,"DDD").       
• Recommended Week formula: =WEEKNUM(B2).       
• Recommended Quarter formula: ="Q"&ROUNDUP(MONTH(B2)/3,0).     
• Recommended Year formula: =YEAR(B2).        
• TotalSales is calculated from Quan ty, UnitPrice and Discount using: =Quan ty*UnitPrice*(1
Discount).            
• Average Order Value (AOV) is calculated by dividing Total Sales by Total Orders using: =Total 
Sales/Total Orders.
